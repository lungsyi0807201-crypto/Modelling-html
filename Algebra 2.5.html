Question 1 Target Time: 1 min

The straight line $L: Ax + By + C = 0$ passes through the first, third, and fourth quadrants only. Which of the following must be true?

Pedagogical Walkthrough:

  1. Quadrant Sketch: Passes through I, III, IV only $\implies$ avoids QII $\implies$ positive slope ($m > 0$) and negative $y$-intercept ($c < 0$).
  2. Formula substitution: Slope $m = -\frac{A}{B} > 0 \implies \frac{A}{B} < 0 \implies AB < 0$.
  3. Constant term check: $y$-int $c = -\frac{C}{B} < 0 \implies \frac{C}{B} > 0 \implies BC > 0$.

Therefore, Option C must be true!

Question 2 Target Time: 1 min

The straight line $L: Ax + By + C = 0$ passes through the second, third, and fourth quadrants only. Which of the following must be true?

Pedagogical Walkthrough:

  1. Quadrant Sketch: Passes QII, QIII, QIV $\implies$ avoids QI $\implies$ negative slope ($m < 0$) and negative $y$-intercept ($c < 0$).
  2. Substitutions: Slope $m = -\frac{A}{B} < 0 \implies \frac{A}{B} > 0 \implies A, B$ have same sign.
  3. Intercept formula: $y$-int $c = -\frac{C}{B} < 0 \implies \frac{C}{B} > 0 \implies B, C$ have same sign.
  4. Transitive deduction: If $A$ shares sign with $B$, and $B$ shares sign with $C$, then $A$ shares sign with $C \implies AC > 0$.

Therefore, Option A must be true!

Question 3 Target Time: 1 min

The straight line $L: Ax + By + C = 0$ has a negative $x$-intercept and passes through the first quadrant, but does not pass through the third quadrant. Which of the following must be true?

Pedagogical Walkthrough:

  1. Quadrant Sketch: Negative $x$-intercept. Passes through QI but avoids QIII. This forces the line to have a negative slope ($m < 0$) and cross the vertical axis above the origin, so $y$-intercept is positive ($c > 0$).
  2. Formula analysis: $m = -\frac{A}{B} < 0 \implies \frac{A}{B} > 0 \implies AB > 0$ (same sign).
  3. Constant checks: $y$-int $c = -\frac{C}{B} > 0 \implies \frac{C}{B} < 0 \implies B, C$ have opposite signs.
  4. Cross sign match: Since $A$ is same sign as $B$, and $C$ has opposite sign to $B$, then $A$ and $C$ must have opposite signs $\implies AC < 0$.

Therefore, Option B must be true!
